Description

The course turns a software engineer into an AI Engineer, able to orchestrate large language models (LLMs) to solve real-world problems. No machine learning background is required: Module 1 provides the basics you need.

The path is progressive: 8 modules with an estimated duration of 58 hours. Each module produces a deliverable that is reused in the following ones, up to the final project: an AI assistant for a real domain (internal documentation, customer support, regulations).

Objectives

By the end of the course you will be able to:

  • explain what an LLM is, how it is trained and how inference works, distinguishing the model from the harness that uses it;
  • design structured prompts (few-shot, chain of thought, validated JSON output), treating them as versioned, testable code;
  • integrate provider APIs, handling retries with backoff, streaming, costs and latency;
  • build a RAG system: ingestion, chunking, embedding and retrieval with source citations;
  • evaluate an LLM application with test datasets, retrieval and generation metrics, and LLM-as-a-judge;
  • design agents with tools, explicit limits and human confirmation for sensitive actions, always starting from the simplest workflow that works;
  • prepare an application for release: observability, cost control, security (OWASP Top 10 for LLM Applications), privacy and the AI Act.
